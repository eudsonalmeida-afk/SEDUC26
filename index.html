Importar questões

JSON ou JSON + imagens
O Banco de Questões é alimentado exclusivamente por importação em JSON. Para questões visuais, selecione o JSON e os arquivos de imagem juntos.

Importação JSON

único método de entrada de questões no banco
Pacote com imagens: selecione de uma vez o arquivo questions.json e todas as imagens usadas nele. No JSON, cada questão pode ter "imageFile":"grafico_01.png". O app associa pelo nome do arquivo e mantém a imagem no armazenamento próprio de mídia. A sincronização entre aparelhos é feita separadamente do progresso, evitando que imagens ocupem o localStorage e bloqueiem o registro do app. Também aceita "imageUrl":"images/grafico_01.png" para imagens hospedadas junto do site.
Imagens antigas: se elas ainda aparecem no celular, os arquivos continuam no IndexedDB. Na V24, toque em “Sincronizar imagens deste aparelho” para enviá-las à área de imagens da nuvem, sem misturá-las ao progresso do app.
